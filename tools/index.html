Git

Worktrees (git worktree)

git worktree listlist worktrees
git worktree add .worktrees/<dir> -b <branch>create new branch + worktree
git worktree add .worktrees/<dir> -b <b> <base>create from specific base
git worktree add .worktrees/<dir> <branch>worktree for existing branch
cd "$(git worktree list | fzf | cut -d' ' -f1)"interactive picker
cd -previous worktree
cd "$(git worktree list | head -1 | cut -d' ' -f1)"main checkout
gh pr checkout 123PR branch (run inside a worktree)
git worktree remove <dir>remove worktree (keeps branch)
git worktree remove --force <dir>remove with uncommitted changes
git branch -d <branch>delete branch after removing
git worktree pruneforget manually deleted folders
git diff main...HEADchanges since branching
git rebase mainrebase onto main
git merge --no-ff <branch>merge from main checkout, keep commits

A branch can be checked out in only one worktree. .worktrees/ is ignored globally.
